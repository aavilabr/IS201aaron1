Hiragana Polar Adventure

A typing adventure on ice

How to play

  1. Select one or more hiragana rows to practice. More rows make the game harder.
  2. Type the romaji for each falling hiragana character before it reaches the bottom.
  3. Earn 100 points for each correct answer. Every third correct answer earns a 500-point combo bonus.
  4. If you miss a character, spend 100 points to continue, or start a new game.
